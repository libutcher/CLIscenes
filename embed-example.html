Sign in to a CLI

This page stands in for a documentation page. The walkthrough below is the static player loaded in an iframe. Run your-cli signin, then approve the request in the desktop app.

Embed code

<iframe
  src="https://docs.example.com/cliscenes/?demo=cli-signin&embed=1"
  title="Interactive walkthrough: sign in to a CLI with a desktop app"
  loading="lazy"
  allow="clipboard-write"
  style="width: 100%; height: 560px; border: 0;"></iframe>

The walkthrough keeps working without the iframe's surrounding page. It only needs the files from dist/ served over HTTP.

Optional: the embedded player posts its height as a cliscenes:height message. This page uses the script below to resize the iframe so it never shows a scrollbar or empty space. 

<script>
  window.addEventListener("message", (event) => {
    if (event.data?.type !== "cliscenes:height") return;
    for (const frame of document.querySelectorAll("iframe")) {
      if (frame.contentWindow === event.source) frame.style.height = event.data.height + "px";
    }
  });
</script>
